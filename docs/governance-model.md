# Governance model

Author: F.M. Robert Vergnes / robert.vergnes@yahoo.fr
Assisted-by: ChatGPT: GPT-5.5 Thinking; Codex

Yellow-control provides an enforcement-oriented governance layer for persistent autonomous agents.

Core model:
- classify requested actions by authority and confidentiality impact;
- apply explicit policy gates before execution;
- enforce backup/rollback checkpoints for core live changes;
- generate auditable governance telemetry.
