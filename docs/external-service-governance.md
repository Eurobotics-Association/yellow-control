# External service governance

Author: F.M. Robert Vergnes / robert.vergnes@yahoo.fr
Assisted-by: ChatGPT: GPT-5.5 Thinking; Codex

External onboarding controls:
- identify service owner and recovery custody expectations;
- classify required ESAL;
- register allowable actions and forbidden actions;
- document secret custody model (names only, never values);
- require explicit approval for privilege expansion.
